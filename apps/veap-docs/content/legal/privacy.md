## 1. Overview

Veap is a free and open-source framework for building modern web applications.

Privacy is important to us. Veap is designed as an open-source software project and does not operate a user account system, collect personal information, or maintain a database of user data.

You can use, download, inspect, modify, and contribute to Veap without providing personal information to the Veap project.

## 2. Data We Collect

Veap does not intentionally collect or store personal data.

The Veap project does not operate:

- user accounts;
- user profiles;
- analytics or tracking systems;
- advertising systems;
- newsletters;
- telemetry;
- payment systems;
- databases containing user information.

Veap does not sell, rent, or share personal data for advertising or marketing purposes.

## 3. Veap Software

The Veap framework and its associated open-source packages run in environments controlled by their users.

Veap does not receive or store the data processed by applications built with the framework.

If you build an application using Veap, any personal data processed by that application is controlled by the operator of that application, not by the Veap project.

The operator of an application built with Veap is responsible for complying with applicable privacy and data protection laws.

## 4. Website and Documentation

The Veap website and documentation are publicly available and do not require an account.

Veap does not use the website to intentionally collect personal information from visitors.

The infrastructure used to host the website may process basic technical information, such as IP addresses or server logs, as necessary to deliver and secure the website.

Such processing may be performed by the relevant infrastructure provider under its own privacy policy.

## 5. Third-Party Services

The Veap project may use third-party platforms for hosting and collaboration, including services such as GitHub and npm.

These platforms operate independently from Veap and may process personal information in accordance with their own terms and privacy policies.

When interacting with these services, their respective privacy policies apply.

## 6. Open-Source Contributions

Veap is an open-source project.

Contributions made to public repositories, including issues, pull requests, discussions, commits, and comments, may be publicly accessible.

Please do not publish personal, confidential, or sensitive information in public project repositories unless you intend for that information to be publicly available.

## 7. Changes

If the Veap project introduces features that involve collecting or processing personal data, this Privacy Policy will be updated before or when such functionality is introduced.

The current version of this policy will always be available on the Veap website.
