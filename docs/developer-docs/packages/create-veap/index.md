# Project scaffolding (`create-veap`)

`create-veap` is the official command-line initializer for scaffolding new Veap + Next.js App Router applications. It copies a verified project template, configures `package.json` for your project name, and installs dependencies using your active package manager.

## Quick start

Run `create-veap` with Bun, pnpm, npm, or Yarn:

```bash
# Using Bun (recommended)
bun create veap my-app

# Using pnpm
pnpm create veap my-app

# Using npm
npm create veap@latest my-app
```

If you omit the project directory name (`bun create veap`), the CLI launches an interactive prompt asking for the target folder and template.
